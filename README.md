# Basel Dental Studio

**A modern, friendly dental practice website concept based in Basel, Switzerland.**

## About the Project

Basel Dental Studio is a fictional dental practice created as a web design and development project. The concept focuses on making dental care feel welcoming, approachable, and professional.

The website is designed to help visitors explore dental services, learn about the practice, and find a straightforward way to request an appointment.

## Design Concept

- **Brand personality:** Friendly, modern, and reassuring
- **Visual direction:** Clean layouts, soft colours, and contemporary typography
- **Target audience:** Adults and families looking for approachable dental care in Basel
- **Main goal:** Encourage visitors to make an appointment enquiry

## Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Status

Website currently in development.

*This is a fictional practice created for a web design recruitment assignment. It does not represent an operating dental clinic.*
